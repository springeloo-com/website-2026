The Produkte page is now CMS-editable, same pattern as Home.

Editors change copy and images in Decap under **Site content → Produkte page**. That writes `src/content/pages/produkte.yaml`. Layout, routes, product/slide **ids**, and the CTA **href** stay developer-owned.

**What editors can change**
- SEO title and description
- Intro headline and image
- Lead kicker, headline, body
- Slider: three slides (name, description lines, image + alt)
- Three product blocks: category, name, optional logo, mock image, features, summary, details
- Open Source section and CTA label

Counts stay fixed at three slides and three products, like Leistungen. A save still opens a PR; production updates only after merge.

The page now loads that YAML at build time. `npm run build` succeeds. I also filled a missing alt on a Home Leistungen image so validation would pass.
