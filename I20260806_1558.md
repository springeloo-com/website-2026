Assuming you mean “why we get **this**” (that deploy log):

**1. `punycode` DEP0040**  
Noise from Node inside `actions/deploy-pages@v5`. Not caused by your site code and does not fail the job.

**2. Timeout warning**  
We set `timeout: 900000` (15 min). The action caps it at **600000** (10 min), so you get that warning and still only wait 10 minutes.

**3. The real problem: `deployment_queued` forever**  
`deploy-pages` did its job: found the artifact, created a Pages deployment for `0e5fb1c…`. After that it only **polls** GitHub Pages. Pages never moves past `deployment_queued` → after ~10 minutes the action aborts/cancels.

So the runner is fine; the **Pages publish queue** for this repo is stuck. Build + artifact upload succeed; CDN publish never starts. That run ended **cancelled** again; live site still won’t update until that queue clears.
