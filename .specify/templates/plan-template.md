## Constitution Check

*GATE: Must pass before Phase 0 research. Re-check after Phase 1 design.*

- **Design-first**: SPEC.md (or feature spec) is derived from the approved Figma
  export; no improvisation when design and code conflict (I, III, XIV)
- **Static-first**: Delivery remains static Astro HTML/CSS with minimal JS;
  no CMS, database, or backend unless explicitly approved (II)
- **Component modularity**: Repeated patterns map to reusable Astro components (IV)
- **Responsive parity**: Desktop/tablet/mobile breakpoints are specified and
  follow Figma, not framework defaults (V)
- **Accessibility & SEO**: Semantic HTML, focus/keyboard/alt text, and metadata
  (titles, descriptions, canonical, Open Graph) are in scope (VI, VII)
- **Minimal dependencies**: New libraries are justified (cost, bundle, support) (VIII)
- **GitHub Pages**: Build/output structure stays compatible with static GH Pages
  + Actions delivery (IX)
- **Spec-driven order**: Analyze Figma → SPEC → plan → implement task-by-task;
  Cursor-friendly, one section/component at a time (X, XI)
- **Maintainability & assets**: Prefer simple solutions; only production assets,
  optimized, predictable paths (XII, XIII)
- **Quality gate**: Done means spec match + successful build + visual check vs
  Figma + responsive/a11y/SEO/static-deploy readiness (XV)

> If any gate cannot be met, record it in Complexity Tracking with justification
> and a simpler alternative that was rejected.
