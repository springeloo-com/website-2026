Rechecked Figma `menue-point-01` — three mismatches were breaking the hover.

**What Figma actually does**
- Desktop instances set `Arrow=false` (no chevron/dropdown)
- Hover only swaps `Default → Mouseover`: underline width `0 → full label`, **300ms ease-out**
- Click navigates; no submenu on hover

**What was wrong**
1. We showed ExpandableNav chevrons + click dropdowns (not in Desktop Figma)
2. Global `a:hover { text-decoration: underline }` fought the custom bar
3. `width: 0 → 100%` on a flex `::after` never resolved (stayed 0px)

**Fix**
- Flat desktop links only (`NavLink`)
- Underline as a real span with `scaleX(0 → 1)`, origin left, 300ms ease-out
- Global hover underline excluded for nav links
- Transparent header uses cream (`#fbf8ef`) like Figma

Preview locally on a hard-refresh (`npm run preview`). Hover a nav label — you should see the cream line grow under the text only. Say if you want this committed/merged to `main`.
