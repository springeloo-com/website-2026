
## Meaning

- Your **user** has Write/Admin on the repo (`push: true`).
- The **token Decap/check used is not a classic OAuth `repo` token**.
- Empty scopes + “integration” ⇒ wrong app type (GitHub App), missing
  `scope=repo,user` on authorize, or org blocking the OAuth App.

Client ID/Secret alone cannot “be allowed to write”; they must mint a `gho_`
token that lists `repo` in `x-oauth-scopes`, then create-ref returns 201.

2. Credentials must come from **OAuth Apps**, not GitHub Apps.
3. Worker `/auth` must include `scope=repo,user` → redeploy from
   `docs/howto-claudflare.md` if needed.
4. Revoke app → re-login → new token.
5. Org owner approves OAuth App:  
   https://github.com/organizations/springeloo-com/settings/oauth_application_policy
6. Re-run `bash scripts/check-oauth-write.sh` until create-ref is **201**.
