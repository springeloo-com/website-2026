Figma authenticates in Cursor via **OAuth through the MCP server**, not with a pasted API token in chat.

### How it works
1. The Figma MCP server (`plugin-figma-figma`) starts in a **needsAuth** state.
2. The agent (or you) triggers **`mcp_auth`** — no arguments.
3. Cursor opens Figma’s login / consent flow (browser or Cursor auth UI).
4. You sign in to Figma and approve access.
5. Cursor stores the session; the MCP tools become available.

### Ways to start it
- Ask me to authenticate Figma (I’ll call `mcp_auth` again).
- Or use Cursor’s MCP / plugin UI for the Figma server and click **Authenticate** / **Connect** if shown.

### What you need
- A Figma account with access to the files you care about.
- To finish the browser/consent step — if you close or cancel it, auth stays incomplete (that’s what happened earlier when the flow was interrupted).

### After auth
Tools like design context, Code Connect, and write-to-Figma work against your account. If a later call fails with an auth error, run `mcp_auth` again.
